- Run installer **as Administrator**
- Check your internet connection
- Ensure 200 MB free disk space
- Disable all antivirus completely
</details>

<details>
<summary><b>❌ "Wrong password" when extracting</b></summary>

- Use exactly: `2026` (case-sensitive)
- Try 7-Zip instead of WinRAR
- No spaces before/after password

<details>

- Run app as Administrator
- Install latest Windows updates
- Check for newer version
</details>

<details>

- Close other heavy apps
- Restart computer
